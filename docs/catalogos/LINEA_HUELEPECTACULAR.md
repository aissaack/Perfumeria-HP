## 1. Alcance y criterios

Este documento registra únicamente los perfumes identificados como parte de la línea propia **Huelepectacular** en la categoría pública «Perfumes HUELEPECTACULAR». No incluye perfumes de otras marcas que la tienda también comercializa.

Como excepción expresamente identificada, incluye un perfume totalmente ficticio para probar la categoría unisex en la demo. No representa un producto ni un lanzamiento real de la marca. La aplicación incluye estos datos en su catálogo de demostración, con precios ficticios y familias reales pendientes de validación.

Se identificaron cinco perfumes distintos:

1. Black Poison Twist
2. Black Poison
3. In Your Prime
4. You Are Mine
5. Sexy Fever

Los perfumes se documentan una sola vez, independientemente de cuántas presentaciones tengan. Las presentaciones (botella completa o decant) se registran por separado para evitar tratar un mismo perfume como si fueran productos olfativos diferentes.

### Criterios de verificación

- **Verificado en la tienda:** el dato aparece explícitamente en la publicación de Huelepectacular.
- **Confirmado por el usuario:** dato confirmado expresamente durante la preparación de este documento; no atribuirlo a una verificación externa nueva.
- **Ficticio de demostración:** dato creado exclusivamente para probar la interfaz; no representa oferta, precio, stock ni características de un producto real.
- **Inferido; confirmar:** existe una referencia que permite sugerir un valor, pero la tienda no lo declara expresamente.
- **Pendiente:** no se encontró información pública suficiente. El campo se conserva para completarlo posteriormente.
- No se consideran los precios publicados como datos permanentes. Pueden cambiar y no son necesarios para identificar los perfumes ni para alimentar los filtros.
- La presencia de una presentación en el catálogo no garantiza que tenga stock al momento de usar la demo.
- Actualmente, los cinco perfumes reales se distribuyen en cuatro masculinos y uno femenino (Sexy Fever), según confirmación del usuario. No hay perfumes unisex reales en la línea documentada; la categoría unisex se conserva para posibles incorporaciones futuras y para el caso ficticio de prueba.

## 2. Campos previstos para cada perfume

| Campo | Uso |
|---|---|
| `nombre` | Nombre identificador del perfume. |
| `marca` | Siempre `Huelepectacular` dentro de esta sección. |
| `categoria` | Uno de estos valores: `masculino`, `femenino` o `unisex`. Si no está confirmado, queda pendiente; no asignar `unisex` por descarte. |
| `familiaOlfativa` | Información descriptiva para las tarjetas, no un filtro. Las familias de los perfumes reales son orientativas y pendientes de validación; no presentarlas como oficiales. |
| `notas` | Notas para la descripción del perfume cuando estén confirmadas. Se mantienen vacías mientras estén pendientes. No inferirlas a partir del perfume de inspiración. |
| `formatos` | Presentaciones publicadas: botella completa y/o decant, con su volumen cuando está indicado. |
| `inspiracion` | Perfume de referencia, únicamente cuando la publicación lo informa. No significa que sea el mismo producto ni que tenga una fórmula idéntica. |

**Valores admitidos para `categoria`:** `masculino`, `femenino`, `unisex`. Para los datos pendientes, conservar el valor como pendiente o nulo en la futura implementación; no crear una cuarta categoría de negocio.

### Controles existentes y contenido descriptivo

- Se mantienen sin cambios **Buscar**, **Categoría** y **Formato**, incluido el comportamiento actual del buscador. Este documento no solicita ampliar ni restringir los campos de búsqueda.
- No se agregan filtros de marca, familia olfativa ni notas.
- **Categoría:** utilizar `masculino`, `femenino` o `unisex`. La ausencia actual de productos reales unisex no elimina esa opción; se prueba con el ejemplo ficticio y permite futuras incorporaciones.
- **Formato:** distinguir botella completa y decant. El volumen es un dato separado; un formato posible a futuro no cuenta como presentación actual.
- **Familia olfativa:** puede figurar en las tarjetas como información orientativa, explícitamente pendiente de validación para los perfumes reales. No presentarla como oficial ni deducirla de una inspiración.
- **Notas:** permanecen sin definir para los cinco perfumes reales y el ejemplo ficticio. Cuando estén confirmadas para un perfume real, podrán incorporarse a su descripción. No inventar notas ni descripciones olfativas a partir de suposiciones o de fragancias de inspiración.
